# Term Project Requirements — Software Architecture

## Minimum Requirements

### Functional scope
- [ ] At least 3 business use cases (+ authentication)
- [ ] Front-end UI for demonstration

### Back-end microservices (must include all of)
- [ ] At least one service using REST
- [ ] At least one service using gRPC
- [ ] At least one service using a message broker
- [ ] API gateway service

### Architecture documentation
- [ ] Describe how Service Discovery is managed

### Data layer
- [ ] At least 2 types of databases: one RDBMS and one NoSQL

### Testing & analysis
- [ ] Load test — at least 2 types, with explanation of results
- [ ] Risk Matrix — conducted and explained
- [ ] Demonstrate at least 1 SW quality/measurement issue (e.g. Scalability, Reusability, Maintainability, Security)
