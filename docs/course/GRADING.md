# Grading Breakdown

## Overall course weighting
- Quiz: 10%
- Assignment from Tutorial: 15%
- Final exam (สอบปลายภาค): 25%
- Term project: 50%

## Term project breakdown (of the 50%)
- Project proposal & ADR: 5% + 3%
- Microservice Design with Collaborations: 2%
- Project progress 1–3 (incl. Git contribution): 5% + 5% + 5%
- Project work product & demo & documentation: 15% + 5% + 5%

## Deliverables implied by grading
- [ ] Project proposal document
- [ ] ADR (Architecture Decision Record(s))
- [ ] Microservice Design doc with collaboration/sequence diagrams
- [ ] Progress checkpoint 1
- [ ] Progress checkpoint 2
- [ ] Progress checkpoint 3
- [ ] Git contribution tracked throughout (per-member commits visible)
- [ ] Final work product (implementation)
- [ ] Demo
- [ ] Documentation
